## Instrucciones de Ejecución

Para reproducir los análisis y estimaciones del modelo final, siga estos pasos:

1. Descargar esta carpeta en su entorno local.
2. Asegurarse de tener instalado Python 3.9 o superior.
3. Instalar las dependencias requeridas ejecutando en la terminal:
   ```bash
   pip install -r requirements.txt
   ```
4. Abrir el archivo `Econometría1_ModeloFinal.ipynb` mediante Jupyter Notebook o VS Code.
5. En la celda número 2, cambiar la ruta mostrada por la ruta del archivo `.csv` en su entorno local.
6. Ejecutar el código secuencialmente.
